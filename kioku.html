      保存について

      • 記録は、このブラウザの中にだけ保存されます。
      • サーバーには送っていません。広告・解析・AI API も使っていません。

      このアプリについて

      タスクの着手を助けるための個人向けアプリです。画面に出すタスクを1件に絞り、 最初の一歩まで分解し、実行の記録を残します。

      • 記録の正確性は保証しません。大事な記録は JSON で書き出してください。
      • 予告なく内容を変更・停止することがあります。

        はじめての方へ

        画面に出るのは、今やること1件だけ。最初の一歩まで分けて、できた／まだを1タップで記録します。

        1. タスクを1つ足す
          「履歴書を送る」のような、終わっていないこと。
        2. 最初の一歩が出る
          「写真を用意する」のように、5分で終わる大きさに分かれます。書き換えもできます。
        3. できた／まだ を押す
          どちらも記録になります。できなかった日も、大事なデータです。

        記録は、いま開いているこの端末のブラウザにだけ保存されます。サーバーには送りません。 他の人には見えません。ブラウザのデータを消すと記録も消えるので、ときどき設定画面から書き出してください。
